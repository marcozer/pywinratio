# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Please be respectful and constructive. Harassment, insulting or derogatory
comments and publishing other people's private information are not acceptable.

To report a problem, contact the maintainers through their GitHub profiles or
open a confidential security advisory on the repository. Reports are handled
confidentially, and contributions or contributors that do not follow this code
may be removed.
